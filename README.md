# Rugby AS

学生アナリストや部活動の指導者が、手軽に試合を記録・分析できる iPhone / iPad 向けのラグビー分析アプリです。

## 作った理由

ラグビーの分析現場で活動する中で、プロのチームが使う映像分析ソフトは高額で、高校や大学のチームでは分析環境を整えにくいと感じました。高価なソフトがなくても、試合の記録から振り返りまでを一つのアプリで行えるようにすることを目指しています。

## 設計の考え方

- **記録の細かさを状況に合わせて選べる**：時間がなければ得点だけ、余裕があれば得点者やプレー内容まで記録できます。記録はすべて後から追記・修正できます。
- **競技形式を決め打ちしない**：7人制・15人制や登録人数をアプリ側で固定せず、どの形式の試合でも同じ仕組みで記録できます。
- **選手名などの情報は任意**：背番号だけでも記録を始められ、名前や写真などは後から足せます。

## 主な機能

- **試合の記録**：得点、プレー、メンバー表、交代を記録。記録画面のボタン配置や記録項目は自由に変更できます。
- **映像との連携**：試合映像（端末内の動画や YouTube）と記録を時刻で結びつけ、タイムラインで振り返り。記録項目ごとにハイライトを書き出せます。
- **集計・分析**：試合・チーム・選手・指標を選んで、合計や成功率を比較。独自の比率指標の作成、試合ごとの推移の表示、CSV レポートの書き出しに対応しています。
- **データの受け渡し**：バックアップファイル（JSON と動画）を AirDrop などで共有できます。
- **公式記録の検索（開発版のみ）**：公式サイトに掲載された試合記録を収集したデータベースから、過去の試合を検索し、自分の記録として取り込めます。

## 使用技術

- **アプリ**：Swift / SwiftUI、SwiftData（端末内保存）、iOS 17 以上。外部ライブラリは使っていません。
- **データ収集ツール**：Python、SQLite（`Tools/official_records`）。日本ラグビーフットボール協会、リーグワン、トップリーグ、ラグビーワールドカップ、HSBC SVNS の公式掲載情報を収集・整理します。相手のサーバーに負荷をかけないよう間隔を空けて取得し、収集元ごとにテストを用意しています。
- **テスト**：回帰テスト（`Tests/`）と、データ収集ツールの単体テスト。

## データの取り扱い

日本ラグビーフットボール協会・リーグワンの利用規約では、掲載情報の複製・配布に事前の許可が必要です。そのため、このリポジトリには収集したデータを含めていません。公式記録の機能は開発版だけで有効になり、配布用のビルドには含めません。詳しくは [`Tools/official_records/README.md`](Tools/official_records/README.md) を参照してください。

## 開発について

生成AI（Claude Code）を活用して開発しています。機能の要件や画面の設計、データの持ち方の判断、実機での動作確認は自分で行っています。開発時の設計メモは [`docs/`](docs/) にあります。
