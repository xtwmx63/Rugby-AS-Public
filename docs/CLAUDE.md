## このアプリは何か

学生ラグビーアナリスト向けの、スタッツ記録・分析ツール（iOS / iPadOS）。

中心思想は「記録の詳細度を状況に合わせて選べる」こと。
時間がなければ得点だけ記録し、余裕があれば得点者まで記録する。
記録したものはすべて後から追記・修正できる。
「簡易か詳細か」の二択ではなく「段階的に詳細化できる」が本質。

設計判断に迷ったら常にこの基準で決める:
すべての情報は「必須ではなく、後から足せる」前提で作る。

ラグビーの形式（セブンズ／15人制、登録人数 12/13/15/23 等）は
アプリ側で固定しない。形式を決め打ちしないことが最も柔軟で、
かつ最も実装がシンプル。記録の仕組みは「何人制か」を知らなくてよい
（大会に 7人制/15人制 の目印を付けるのは表示用で、記録は縛らない）。

## 技術前提

- 言語: Swift / UI: SwiftUI
- 対応: iOS 17 以上、iPhone と iPad（Mac 対応は見送り済み・再挑戦しない）
- データ保存: 端末内ローカル保存（SwiftData）。クラウド同期はしない
  （共有はバックアップファイルを AirDrop / LINE 等で受け渡す）
- 外部ライブラリは原則使わない。標準フレームワークで実装。
  （公式記録の収集ツール Tools/official_records だけは開発用に Python を使う。アプリには入れない）
- アーキテクチャは最初はシンプルに。過度な抽象化は避ける。
- バージョン管理は git / GitHub（xtwmx63/Rugby-AS、main ブランチ）。
  機能の区切りごとにコミットし、こまめに GitHub へ push する
  （手元の Mac が壊れても戻せるようにする。未経験者の保険）。

## データ構造（背骨は崩さない）

SwiftData のモデルは Models.swift の 7 つ。

- Team: 自チームも相手チームも対等にこの1つで扱う。カテゴリー（自由入力）・ロゴ・色。
- Player: チームに属す。背番号 number は任意（nil=背番号なし）、名前も任意。
  読み・英語表記・写真・ポジション・身長体重など属性は全部任意。
- Tournament: 正式名称＋年度（同名大会を年度で束ねる）・ロゴ・7/15人制・形式・出場チーム。
- Match: 大会と2チームを参照（自チーム固定にしない）。記録画面の配置・途中状態も持つ。
- StatEvent: 全種類の記録を1テーブルで受ける。category / outcome / seconds / half / origin 等。
  player_id・team_id は任意。新しい記録項目は category の追加で対応する。
- MatchLineup: 試合ごとのメンバー表。**試合時点の背番号をここに控える**。
- Substitution: 交代記録。

設計の背骨は2つの任意フィールド:
Player.name 任意 → 背番号だけで記録開始できる。
StatEvent.player_id 任意 → 選手不明でも記録し後から紐づけ。

守るべき約束:
- 集計値は保存せず、常に StatEvent から計算し直す（後から記録を足しても正しくなる）。
- 背番号の表示は必ず MatchNumbering を通す（ラグビーは固定背番号がないため、
  過去試合の番号はメンバー表に控えた値を使う）。
- StatEvent.seconds は「試合時計の秒」。動画の位置との変換は MatchVideoClock /
  MatchVideoTimeline を通す（直接「動画の秒」として扱わない）。
- 保存は `AppPersistence.save(context)` を使う（失敗したら画面に知らせるため。
  `try? context.save()` で黙って流さない）。
- バックアップ（BackupManager）に項目を足したら、古いファイルも読めるようにする。

## 今ある機能（2026-09 時点）

- 試合一覧・試合作成・チーム／選手名簿（カード表示・一括入力）・大会（順位表・ランキング）
- 記録画面は従来の記録画面（V3RecordingView）を使う。カスタム記録画面（WidgetRecordingView・
  配置を自由に作れる）はコードに残しているが、2026-10-13 から画面からは開かない
- 試合サマリー・プレー一覧の編集・得点経過グラフ・画像共有・CSV 書き出し
- 動画: タイムライン編集・キックオフ合わせ・ハイライト書き出し・長い配信の試合ごと分割
- 分析: 試合をまたいだ比較・条件の組み合わせ・保存できるレポート
- 公式記録: JRFU／リーグワンの試合結果を検索し、確認画面を経て自分の試合として取り込める
  （アプリ同梱の読み取り専用 DB。規約上の許可が取れるまで開発版(Debug)のみ）
- バックアップ（JSON＋動画）と復元
