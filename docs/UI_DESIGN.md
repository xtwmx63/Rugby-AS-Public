# Rugby AS UI refresh

## 対象

試合一覧・試合作成・メンバー登録・試合サマリー・チーム一覧・分析／比較・設定。
ユーザーが選んだPremier Leagueアプリの方向性をもとに、白い情報面・濃紫の見出しと主要操作・
ピンクの比較アクセントへ更新した。ネイビー×ライムの初案を置き換えている。
データモデル、記録形式、集計・保存・バックアップの仕組みは維持している。

## 現在の方向性: Premier Leagueを参考にした紫×白

- [Premier Leagueの試合詳細](https://mobbin.com/screens/23dce6cf-7ec9-4bd5-b8a2-6adc573f8eb4): 濃紫のヘッダー、白いスコア面、切り替えタブ、左右を比較する細いバー。
- [Premier Leagueの結果一覧](https://mobbin.com/screens/f5574e13-9588-46cf-930e-6ce87279efc7): 白い一覧と紫のスコア表示、罫線で区切る情報。
- 試合一覧は中央のスコア表示を強調し、カードの余白と角丸を縮小。
- 試合詳細は「概要・スタッツ・メンバー」に整理。前後半の範囲、CSV出力と全指標の画像共有を維持。
- メンバー表は写真カードのグリッドから、背番号・写真・名前を揃えた行表示へ変更。登録は引き続き任意。
- 分析は紫の棒グラフと白い指標面、罫線の比較一覧へ変更。チーム・設定・試合作成も共通テーマへ統一。
- HOME/AWAYは統計全体で紫/ピンクを使用し、チームロゴの元色は維持。
- 既存の記録・動画画面、およびチームの選手カード編集は暗い表示を維持するよう外観を明示。
- 他社のロゴ・画像・フォントをアプリへ組み込まず、SwiftUIの標準部品で実装。

### 紫×白デザインの確認結果

- Simulator向けDebugビルド、既存の回帰チェック、公式記録のチェックがすべて成功。
- iPhone 17 Pro / iPad Pro 11-inchで主要7画面を確認。
- 試合詳細の3タブと前後半の切り替え、得点・セットプレー集計の更新を確認。
- 共有画像の生成とプレビュー表示を確認。以前の画面操作ツールによる未確認事項は解消。
- iPadの最大アクセシビリティ文字サイズで試合詳細を確認し、通常サイズに復元。
- メンバー登録のチーム切替と記録画面への遷移を確認。
- 暗い記録・動画画面には標準の青い操作色を指定し、濃紫が継承されて読みにくくなることを防止。
- 試合一覧・詳細のステータスバーは白地として時刻や通信状態を読みやすくした。

## 操作の改善

- 試合一覧: 作成ボタンにラベルを表示。チーム名・大会名検索、記録状況フィルター、検索条件の解除を追加。
- 大会一覧と配信分割: 試合一覧の右上メニューに集約。
- 試合カード: 大会／日付、記録状況、チーム／得点、前後半得点、遷移先の順に整理。過去の月には年も表示。
- チーム: 名前／カテゴリー検索、カテゴリごとの件数、新規追加後の編集画面への遷移。
- 分析: 集計条件を折りたたみ、記録数・成功率・比較グラフを優先。既存のレポート、対象試合、除外設定を維持。
- 設定: 初期設定とバックアップ／移行を分け、操作内容と最終ファイル作成状況を明示。
- アクセシビリティ: 選択状態の読み上げ、前後半得点の読み上げ、大きい文字での縦配置。

## 続きの改善: 試合の準備と振り返り

- 試合作成: 大会、ホーム／アウェイ、試合日を共通カードで整理。保存できない理由を表示し、「保存して記録開始」を主操作、「保存のみ」を副操作にした。
- メンバー登録: 未登録でも記録できることを明示。チーム名付きの切り替え、選手の番号編集・解除の操作を整理し、下部に「記録画面を選ぶ」を固定。通常の戻る操作も表示。
- 試合サマリー: 大会／日付、スコア、前後半をまとめ、プレー編集・動画分析・記録への入口を整理。戻るボタンと画像／CSV共有はスクロール中も使える。
- 指標: 得点内訳とセットプレーはiPhoneで縦並び、iPadで横並び。割合を算出できないポゼッション、記録のないセットプレー成功率は「—」と表示する。計算式は変更していない。
- 画像共有: 書き出しに使うロゴはキャッシュの準備状態によらず読み込み、プレースホルダーの混入を防ぐ。
- 参考: [Apple Sportsの試合詳細](https://mobbin.com/screens/f22c0688-fc14-4d38-af6c-3e7d52a17a8a)の左右チーム比較と、[NBAのサマリー](https://mobbin.com/screens/2a85cf45-0207-498a-afe1-65473c8d3bae)の指標のまとめ方。

## チーム成績（2026-09-29）

- 基準はPremier Leagueの[比較画面](https://mobbin.com/screens/20854574-a9a3-4acb-b20e-3de8f4f7f854)と[ランキング画面](https://mobbin.com/screens/7b45ef3b-ced3-45e0-ac1e-ca7d371b6520)。白い情報面、濃紫のタブ、揃えた数値を使用する。
- 設定したチーム色は自チームのグラフ・小さいアイコン・順位1位などに限定。バー・グラフ・順位バッジは設定色をそのまま使い、小さい文字と操作色だけ読みやすい濃さへ補正する。得点は実線＋丸、失点はチャコールグレーの破線＋四角で区別する。サマリー・対戦相手・年度別成績の勝敗バーは勝ち＝自チーム色、負け＝チャコールグレー（同じ色を凡例にも使用）、引き分け＝灰色に統一する。
- チーム詳細の成績入口は大きな独立カードから、チーム名の直下の「選手名簿／チーム成績」へ移動。名簿管理とチーム全体の分析を最初に選べる。
- サマリー、対戦相手、試合の3タブ。得失点の試合別推移は直近5・10・全試合、得点／失点と得失点差を切替可能。グラフは0基準を含む実測値で、異なる年の日付は年も表示する。
- 表示カスタマイズは推移・直近の結果・ランキングの3スイッチに限定し、次回も保持する。
- 直近の結果は相手チームのロゴ付きで横5列。見出し右のメニューで5・10・15・20・25・30試合を選び、最大6行まで表示する。スコア背景は選手概要と同じ勝ち＝緑・負け＝赤・引き分け＝灰。平均得点とサマリーの勝率は設定したチーム色、平均失点は共通のチャコールグレーを使う。試合結果右上の勝敗マークも、勝ち＝補正しないチームカラー、負け＝同じチャコールグレーに揃える。
- チーム内ランキングは得点・トライ・コンバージョン成功数・コンバージョン成功率を選択できる。成功率は成功／試行（成功＋失敗）で計算し、最低試行本数は初期5本、メニューと任意の整数入力で変更・保存する。選択中の年度・対戦相手と同じ試合集合で集計し、同数・同率は同順位（同率内は試行数の多い順）。キッカー不明・成否不明を成功率に含めず、0%でも最低試行本数を満たせば表示する。
- 1位は大会ランキングと共通の写真付きLeaderCardで表示し、同率1位にも同じ扱いを適用する。2位・3位は数字背景を銀・銅にする。選手不明と認定トライは個人順位に入れず、未帰属の量を明示する。選手を押すと個人成績へ進める。
- 実データは変更せず、サンプルの動線確認は `--design-preview --design-section teams`、年度をまたぐ試合確認は `--design-preview --design-section team-performance` を使う。
- 30試合の表示上限は上記のチーム成績プレビューに `--design-recent-30` を追加して確認できる。
- キックランキングのカードと銀銅順位は `--design-rankings` を追加して確認できる。
